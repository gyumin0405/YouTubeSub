# YouTube Custom Subtitles

SRT/VTT 자막 파일을 유튜브 영상에 직접 띄워주는 크롬 확장 프로그램입니다.

## 주요 기능

- `.srt` / `.vtt` 자막 파일을 불러와 현재 보고 있는 유튜브 영상에 표시
- 영상별로 자막이 저장되어, 같은 영상을 다시 열면 자동으로 적용
- 싱크 조절(±0.1초 / ±0.5초 단위)로 자막 타이밍 미세 조정
- 자막 크기 조절(모든 영상 공통 설정)
- 등록된 자막 목록을 검색하고 삭제하는 기능 (유튜브 영상 페이지가 아니어도 확인 가능)

## 설치 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. 크롬에서 `chrome://extensions` 접속 후 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 버튼을 눌러 이 저장소 폴더를 선택합니다.

## 사용 방법

1. 유튜브 영상 재생 페이지에서 확장 프로그램 아이콘을 클릭합니다.
2. **자막 파일 선택**으로 `.srt` 또는 `.vtt` 파일을 불러옵니다.
3. 필요하면 싱크·크기를 조절합니다.
4. 등록한 자막은 확장 프로그램 팝업의 **등록된 자막 목록**에서 언제든 검색·삭제할 수 있습니다.

## 폴더 구조

```
manifest.json         # 확장 프로그램 매니페스트 (Manifest V3)
content/               # 유튜브 페이지에 주입되는 content script (자막 렌더링)
popup/                 # 확장 프로그램 팝업 UI
```
